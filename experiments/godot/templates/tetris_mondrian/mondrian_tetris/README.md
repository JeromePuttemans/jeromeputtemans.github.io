# 🟥🟦🟨 Mondrian Tetris

Un Tetris classique habillé dans le style de **Piet Mondrian** :
- Grille de lignes noires épaisses
- Pièces en rouge primaire, bleu primaire et jaune
- Panneaux décoratifs inspirés de *Composition II* (1930)
- Fond blanc cassé

## Prérequis

**Godot Engine 4.x** (4.1 ou supérieur)  
→ https://godotengine.org/download

## Lancer le jeu

1. Ouvrir Godot 4
2. Cliquer **"Import"** et sélectionner le dossier `mondrian_tetris/`
3. Cliquer **"Import & Edit"**
4. Appuyer sur **F5** (ou le bouton ▶) pour lancer

## Contrôles

| Touche     | Action         |
|------------|---------------|
| ← →        | Déplacer       |
| ↑          | Rotation       |
| ↓          | Descente rapide|
| Espace     | Drop immédiat  |
| R / Entrée | Rejouer        |

## Système de points

| Lignes | Points (× niveau) |
|--------|-------------------|
| 1      | 100               |
| 2      | 300               |
| 3      | 500               |
| 4      | 800               |

Le niveau augmente tous les 10 lignes — la vitesse aussi !

---
*Inspiré de Piet Mondrian, "Composition en rouge, bleu et jaune" (1930)*
